# Affiliate Marketing Project Status Dashboard

A simple Streamlit dashboard that helps affiliate marketers track their campaign progress, budget spending, completed tasks, and remaining campaign days.

---

## Project Overview

This project was created using Python and Streamlit to provide a clean and interactive status page for affiliate marketing management.

The dashboard displays:

- Budget spent on marketing campaigns
- Number of completed tasks
- Remaining campaign days
- Sales progress tracking
- Simple project status overview

This project is useful for affiliate marketers who want to monitor their workflow and campaign performance in a lightweight dashboard.

---

## Features

- Interactive Streamlit interface
- Budget tracking system
- Task completion monitoring
- Campaign countdown
- Clean dark-themed UI
- Beginner-friendly Python project
